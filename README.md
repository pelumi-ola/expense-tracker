# Expense Tracker

## Project Topic

A simple web application that allows users to record, manage, and track their daily expenses.

## Project Type

Full-Stack Web Application

## Planned Technologies

* React.js
* Node.js
* Express.js
* MongoDB
* REST API

## Main Features

* Add a new expense
* View all expenses
* Edit an expense
* Delete an expense
* Categorize expenses
* Calculate total expenses

## Project Description

The Expense Tracker will help users keep track of their spending by providing a simple platform for recording and managing expenses.

Users will be able to add expenses with details such as the amount, description, category, and date. They will also be able to update or delete existing expenses and view their total spending.

## Project Status

Lab Phase – Draft Repository

## Goal

The goal of this project is to develop a simple full-stack application while applying concepts such as frontend development, REST API development, database management, and CRUD operations.
